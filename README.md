# NEON VERTIGO — Kings of Coope City

**3.6.3 — International Edition · Español / English**

A cyberpunk anti-gravity racing game for the browser: conquer three territories, challenge Sony, Vader and Cooper, and race for the crown of Coope City. Includes thirteen circuits, six ships, takedowns, boost, a 3D hangar and adaptive music.

**[Play on GitHub Pages](https://adinlm.github.io/neon-vertigo/)**

Choose **ESPAÑOL** or **ENGLISH** when opening the game. Your preference is remembered; you can switch in Settings without changing your campaign. Both languages, including 324 boss dialogue lines each, are built into the same HTML file.

## Play online or offline

The complete `index.html` is about 31.2 MB and includes its graphics and audio. Allow time for the first download. Download the file and open it in a modern Chromium browser to play offline, without installation, login, translation services or remote language files.

Designed for desktop and mobile browsers. Use landscape orientation for racing; the language selector and ending screens also support portrait orientation. Galaxy Z Fold5 physical-device validation remains a player test; no blanket device or performance guarantee is claimed.

## Controls

| Input | Action |
| --- | --- |
| Touch: left-side joystick | Steer and change altitude |
| Touch: right-side buttons | Accelerate, brake and boost; automatic acceleration is available in Settings |
| A / D or Left / Right | Steer |
| W / S | Change altitude |
| K / Up | Accelerate |
| J / Down | Brake |
| L / Space | Boost |
| P / Escape | Pause |

Ram rivals from the side or behind for takedowns. Avoid head-on traffic collisions. Adaptive music responds to race events and rivals, with a dedicated orbital soundtrack and synthesized effects.

## Campaign and ships

- Start with **STRIX-01** and **RAZOR-X**.
- Defeat Sony, Vader and Cooper to unlock **FANG GT**, **IRON WRAITH** and **SOVEREIGN**.
- Conquer all three territories to unlock **THE CROWN**.
- Win all ten campaign events on Easy or Normal to unlock Hard.
- Win all ten events on Hard to reveal **PROJECT ZERO**, the final reward.
- Track cards show the difficulties already completed. Campaign badges require wins; free-race badges indicate recorded finishes. Legacy saves without difficulty evidence are labelled explicitly.
- Free races do not clear campaign challenges. There are no public unlock-all or diagnostic controls.

## Saves

Progress is stored in your browser. Use **SAVE DATA / PARTIDA** to export, back up or import your campaign. The downloaded HTML and the website have separate browser origins, so transfer saves explicitly when moving between them. Valid previous campaign saves are preserved; separate old diagnostic storage is ignored.

## Español

Juego de carreras antigravitatorias cyberpunk, con trece circuitos, tres territorios, seis naves, campaña, takedowns, turbo, hangar 3D y música adaptativa. **[Juega aquí](https://adinlm.github.io/neon-vertigo/)**.

Elige Español o English al abrir el juego; también puedes cambiar el idioma desde Ajustes sin perder progreso. Puedes descargar `index.html` para jugar offline. En móvil usa orientación horizontal: joystick a la izquierda y controles a la derecha. Exporta tu partida desde **PARTIDA** antes de cambiar de navegador, dispositivo o entre la web y el archivo local.

Gana los diez eventos en Fácil/Normal para habilitar Difícil y después complétalos en Difícil para revelar PROJECT ZERO. Cada pista muestra sus dificultades completadas, usando victorias de campaña o registros de llegada en carrera libre según corresponda.
